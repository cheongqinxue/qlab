Univariate ops + gated FFN blocks used in modern transformers (2024–2026 stack).

Activation functions

What “latest” means here

Decoder LLMs mostly dropped plain ReLU FFNs for gated linear units (GLU) with smooth gates (SwiGLU or GEGLU). Vision and diffusion stacks still mix GELU, SiLU, and ReLU². Research targets stable low-precision pre-training (e.g. PowLU, clipped SwiGLU).

Common univariate shapes (FFN or gate nonlinearity).

Gated FFN pattern

Up-project, gate, then down-project back to model width:

h = act(x W_gate) ⊙ (x W_value)   # width d_ff
y = h W_down                        # W_down: d_ff → d_model
SwiGLU FFN block (PyTorch) 
import torch.nn as nn
import torch.nn.functional as F

# d_model = hidden_size, d_ff = intermediate_size (often ⌊2/3 · 4·d_model⌋)

gate_up = nn.Linear(d_model, 2 * d_ff, bias=False)  # fused up-proj
down    = nn.Linear(d_ff, d_model, bias=False)

def swiglu_ffn(x):          # x: (..., d_model)
    gate, up = gate_up(x).chunk(2, dim=-1)   # each (..., d_ff)
    h = F.silu(gate) * up                    # element-wise; same as SiLU ⊙
    return down(h)          # (..., d_model); block output is often x + dropout(down(h))

F.silu = SiLU (β = 1); see SiLU cell.

LLaMA-style code sometimes uses three layers (w1 gate, w3 up, w2 down) instead of fused gate_up — same math. nn.Linear stores weight shape (out_features, in_features), so gate_up(x) is x @ weight.T. Default in LLaMA, Mistral, Qwen, OLMo, DeepSeek-style decoders.

GEGLU 
GEGLU(x) = GELU(xW) ⊙ (xV)

GELU — gate nonlinearity in GEGLU blocks.

Used in Gemma, T5 v1.1, many diffusion U-Nets. Small-scale LM studies sometimes show slightly lower val loss vs SwiGLU; at large scale the gap is often architecture-specific.

ReGLU 
ReGLU(x) = max(0, xW) ⊙ (xV)

ReLU — gate nonlinearity in ReGLU.

Gated ReLU variant from the same GLU family; less common in open LLMs than SwiGLU/GEGLU.

GELU 
GELU(x) = x · Φ(x)   # Φ = standard normal CDF
≈ 0.5x(1 + tanh(√(2/π)(x + 0.044715x³)))

BERT, GPT-2/GPT-3 FFNs; still the univariate nonlinearity inside GEGLU.

SiLU / Swish 
σ(x) = 1 / (1 + e^(−x))          # logistic sigmoid

Swish_β(x) = x · σ(βx)           # β (or α): input scale
SiLU(x)    = Swish_1(x) = x · σ(x)   # β fixed at 1

The Swish scale β (sometimes written α) stretches the input before the sigmoid: larger β → sharper gate; smaller β → softer. Original Swish allowed learnable β; SiLU fixes β = 1. SwiGLU uses that fixed SiLU gate. Smooth bump for x < 0, then ~linear for large positive x.

Mish 
Mish(x) = x · tanh(softplus(x))

Smooth, self-gated; occasional vision/backbone choice without GLU width doubling.

ReLU² 
ReLU²(x) = (max(0, x))²

Steeper than ReLU for x > 0; flat at zero for x ≤ 0.

ReLU (baseline) 
ReLU(x) = max(0, x)

Original Transformer FFN; zero gradient for x < 0.

Quick / Fast GELU 
QuickGELU(x) ≈ x · σ(1.702x)

Full GELU vs sigmoid approximation (inference kernels).

SwiGLU + clamp

Stacks clamp gate inputs before SiLU to limit outliers in FP16/BF16. Same wiring as SwiGLU; gate sees clip(x, −c, c) before SiLU.

Example clamp at ±3 on the gate input.

PowLU (research) 
f(x)=x^(m/(√x+1))·σ(x)  for x>0  (m≈3)
x≤0: same tail as SiLU / SwiGLU gate

PowLU sublinear growth for large positive x vs SiLU.

Softmax (attention) 
softmax(z)_i = exp(z_i) / Σ_j exp(z_j)

σ(x) — binary softmax; full softmax is vector-normalized exp.

Where models land
  • SwiGLU orbit: LLaMA 2/3, Mistral/Mixtral, Qwen, OLMo, Command R, many MoE decoders.
  • GEGLU: Gemma family, T5 v1.1, much diffusion.
  • GELU-only FFN: older GPT-2/3, BERT-style encoders.
Implementation notes
  • Fused kernels expect last dim 2d then split (vLLM SiluAndMul / GeluAndMul).
  • Convention varies: silu(gate)*value vs value*silu(gate) — match checkpoint.
  • When swapping GEGLU ↔ SwiGLU, retune width for parameter parity.
