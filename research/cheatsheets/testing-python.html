Testing — Python, pytest & mocks

pytest layout

Put tests under tests/ mirroring package names. Files and functions start with test_; classes with Test. One test should exercise one behavior; use fixtures for shared setup. Mark slow or integration tests (@pytest.mark.integration) so CI can split fast vs slow jobs.

Arrange – act – assert 
def test_discount_applies_once():
    cart = Cart(items=[Item(price=10.0)])
    cart.apply_coupon("SAVE10", percent=10)

    assert cart.total() == pytest.approx(9.0)

Use pytest.approx for floats. For async code, prefer @pytest.mark.asyncio on the test or asyncio.run() in a thin sync wrapper when the suite is mostly sync.

Fixtures and conftest.py

conftest.py holds fixtures visible to sibling tests — ideal for env vars, temp config paths, and shared clients. Scope function (default) gives isolation; session shares expensive setup (e.g. one Docker DB) when tests are read-only. 

@pytest.fixture
def api_client(tmp_path: Path) -> TestClient:
    os.environ["DATA_DIR"] = str(tmp_path)
    from myapp.main import app
    return TestClient(app)
Test doubles — pick the right one
Kind Use when
Stub Return canned data; no assertions on how it was called
Mock Verify calls (args, count); simulate failures
Fake Working in-memory impl (fake S3, sqlite instead of postgres)
Spy Real object with call recording wrapped around it

Prefer fakes and real local deps for integration confidence; use mocks at system boundaries you do not own (cloud APIs, billing, live LLM).

Mock complex systems — pattern 1: env + fixture mode

Production code reads config from the environment; tests point it at fixtures and disable bootstrap side effects. Same pattern as agent harnesses: set *_AGENTS=fixture, empty observability keys, in-memory backends. 

@pytest.fixture(autouse=True)
def service_test_env(monkeypatch: pytest.MonkeyPatch, tmp_path: Path) -> None:
    monkeypatch.setenv("APP_CONFIG", str(tmp_path / "config.json"))
    monkeypatch.setenv("USE_LIVE_LLM", "0")
    monkeypatch.setenv("LANGFUSE_SECRET_KEY", "")
    monkeypatch.delenv("AWS_PROFILE", raising=False)
Pattern 2: monkeypatch.setattr on the import site

Patch where the name is looked up, not where it is defined. Replace heavy builders (build_runtime, get_openie_extractor) with lambdas returning test doubles. 

def test_index_route_uses_stub_extractor(monkeypatch: pytest.MonkeyPatch) -> None:
    stub = StubExtractor(entities=[("Paris", "GPE")])
    monkeypatch.setattr("server.routes.index.get_openie_extractor", lambda: stub)

    response = client.post("/index", json={"text": "Paris is nice."})
    assert response.status_code == 200
    assert stub.call_count == 1
Pattern 3: unittest.mock.patch for context managers 
from unittest.mock import MagicMock, patch

@patch("myapp.storage.boto3.client")
def test_upload_calls_s3(mock_boto_client: MagicMock) -> None:
    s3 = MagicMock()
    mock_boto_client.return_value = s3

    upload_report(b"csv-bytes", key="runs/abc/metrics.csv")

    s3.put_object.assert_called_once()
    _, kwargs = s3.put_object.call_args
    assert kwargs["Key"] == "runs/abc/metrics.csv"

Assert on behavior you own (correct key, bucket, content type), not every boto internal call.

Pattern 4: fake HTTP with responses or httpx mock 
import httpx
import respx

@respx.mock
def test_webhook_retries_on_503() -> None:
    route = respx.post("https://partner.example/hook").mock(
        side_effect=[httpx.Response(503), httpx.Response(200)]
    )
    send_webhook({"event": "done"})
    assert route.call_count == 2

For FastAPI/Starlette, TestClient exercises your app without binding a port; still mock outbound HTTP to third parties.

Pattern 5: cloud storage (GCS / S3) without the cloud

Option A — inject a storage interface; fake stores blobs in a dict[str, bytes]. Option B — use emulator or moto (AWS) for integration tests. Option C — patch the client method that your code calls (bucket.blob().upload_from_string) to write to tmp_path. 

class FakeBlob:
    def __init__(self, store: dict[str, bytes], name: str) -> None:
        self._store, self.name = store, name

    def upload_from_string(self, data: bytes, **_: object) -> None:
        self._store[self.name] = data

class FakeBucket:
    def __init__(self, store: dict[str, bytes]) -> None:
        self._store = store

    def blob(self, name: str) -> FakeBlob:
        return FakeBlob(self._store, name)
Pattern 6: W&B / experiment trackers

Never hit the cloud in unit tests. Set WANDB_MODE=disabled or mock wandb.init / wandb.log to no-ops that record calls in a list for assertions. 

@pytest.fixture(autouse=True)
def no_wandb(monkeypatch: pytest.MonkeyPatch) -> None:
    monkeypatch.setenv("WANDB_MODE", "disabled")

def test_training_logs_loss_once(monkeypatch: pytest.MonkeyPatch) -> None:
    logged: list[tuple[str, float]] = []
    monkeypatch.setattr("wandb.log", lambda metrics: logged.append(("loss", metrics["loss"])))
    train_one_step(model, batch)
    assert len(logged) == 1
Pattern 7: LLM and agent chains

Unit tests should not call OpenAI. Inject a fixture LLM that returns scripted tool calls or JSON from a file. Test orchestration: correct tool selected, args parsed, errors surfaced. Quality of natural language belongs in golden eval (ML testing), not in mocked unit tests. 

class ScriptLLM:
    def __init__(self, replies: list[str]) -> None:
        self._replies = list(replies)

    def complete(self, prompt: str) -> str:
        return self._replies.pop(0)

def test_agent_calls_search_tool():
    llm = ScriptLLM(['{"tool":"search","args":{"q":"qlab"}}', "Done."])
    agent = Agent(llm=llm, tools=[SearchTool()])
    result = agent.run("find qlab docs")
    assert "Done." in result
Pattern 8: database — testcontainers vs sqlite

Sqlite in-memory is fast for SQLAlchemy models if you avoid postgres-only features. For postgres-specific SQL (JSONB, RLS), use a disposable postgres (Docker / testcontainers) in an integration job. Wrap each test in a transaction rollback or truncate tables in fixture teardown for isolation.

Pattern 9: time, randomness, and async sleeps 
def test_token_expires(monkeypatch: pytest.MonkeyPatch) -> None:
    t = {"now": 1_000_000.0}
    monkeypatch.setattr("myapp.auth.time.time", lambda: t["now"])
    token = issue_token(ttl_sec=60)
    t["now"] += 61
    assert is_expired(token)

Fix seeds for numpy/torch in tests that touch sampling. Avoid time.sleep in unit tests — patch clocks or use deterministic schedulers.

Anti-patterns
  • Mocking your own domain logic so the test only checks the mock — you tested nothing.
  • Shared mutable globals between tests — order-dependent flakes.
  • Asserting exact LLM prose in unit tests — brittle; use schema and tool-call assertions instead.
  • Catching broad exceptions in production code just to satisfy coverage — test real error types.
