Transformers — core & attention

Block anatomy (most stacks)
  • Embed — tokens / patches / frames → vectors (+ position)
  • Layer — pre-norm → attention → residual → pre-norm → FFN (often SwiGLU) → residual
  • MoE layer — same attention; FFN replaced by router + top‑k experts (see MoE cell)
  • Head — logits, class, noise ε, mel, latents, etc.

AdamW + warmup; FFN: SwiGLU.

MoE FFN block (sparse compute)

Attention stays dense; the feed-forward sublayer becomes a router plus $N$ expert FFNs (each usually SwiGLU-shaped). Each token activates only top‑k experts; outputs are combined with router weights.

$$y=\sum_{i\in \mathrm{TopK}(g)} g_i(x)\,\mathrm{Expert}_i(x),\quad g=\mathrm{softmax}(W_g x)$$

Train/serve: efficiency sheet — MoE. Examples: Switch, Mixtral, DeepSeek-MoE class.

Three families
  • Encoder-only — bidirectional self-attn (BERT, ViT). MLM / classify / embed
  • Decoder-only — causal self-attn (GPT, LLaMA, DiT denoiser)
  • Encoder–decoder — enc full context; dec causal + cross-attn (T5, Whisper)
Multi-head attention (MHA)

Original Transformer block: run several attention heads in parallel, then mix with an output projection.

$$\mathrm{head}_i=\mathrm{SDPA}(XW_i^Q,\,XW_i^K,\,XW_i^V),\quad \mathrm{MHA}(X)=\mathrm{Concat}(\mathrm{head}_1,\ldots,\mathrm{head}_h)\,W^O$$
  • $h$ heads; per-head dim $d_k$ (often $d_{\mathrm{model}}/h$)
  • Each head has its own $W_i^Q,W_i^K,W_i^V$ → distinct $K,V$ to cache at inference
  • Self-attn: same $X$ for Q/K/V; cross-attn: Q from decoder, K/V from encoder
  • Quality reference; KV cache largest vs MQA / GQA / MLA
SDPA — one head’s operator
$$\mathrm{SDPA}(Q,K,V)=\mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$
  • Same math inside every head of MHA (and most variants below)
  • Cost per head $\mathcal{O}(n^2 d_k)$; MHA multiplies by $h$ for Q/K/V proj + cache
  • PyTorch scaled_dot_product_attention = fast SDPA kernels, not a new attention type
Attention map (2024–26)
  • MHA — full Q/K/V per head (BERT, GPT-2, ViT)
  • MQA / GQA — share K,V across heads; same SDPA
  • MLA — cache low-rank latent, then up-project K,V
  • Sparse / window — fewer $(q,k)$ pairs; often still softmax
  • DiffAttn — difference of two softmax maps (scoring change)
  • Details: efficiency sheet
Positional information
  • Absolute — sinusoidal or learned add to embed (original Transformer, BERT)
  • Relative — distance bias on scores (T5, some speech)
  • RoPE — rotate $q,k$; see next cell
  • Implicit — patch / window order only (ViT, Swin)
RoPE (rotary position embedding)

Pairs of dims in $q,k$ rotated by angle $m\theta_i$ at position $m$.

$$f(x,m)=x e^{i m\theta}\quad\text{(complex view on consecutive dims)}$$
  • Relative structure in $q^\top k$; no separate position vector
  • LLaMA, Mistral, Qwen, many encoders
  • Long context: NTK / YaRN scaling, position interpolation
