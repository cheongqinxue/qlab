Failure modes

What this sheet is

A failure mode is something that breaks or distorts training dynamics: loss blows up, gradients disappear, Adam takes insane steps, or representations become useless. That is different from a generalization gap, where training completes but validation stays poor (generalization sheet). Here you fix stability and signal flow first; then you re-read val curves.

Each mode below has a qlab id used in pathology tutorials. Longer notes with citations live in tutorials/pathologies/doc/failure-modes/*.md.

Mode collapse (concept)
What it is

Mode collapse means the model puts almost all probability mass on a small set of behaviors — the same phrases in RL, the same images in GANs, the same safe answer for every prompt — instead of covering the diverse training or reward landscape. Training loss or reward can look “okay” while diversity is gone.

LLM RL / PPO

Policy chases a narrow reward hack (length, format, RM favorite tic). Policy entropy crashes; samples look copy-pasted.

  • Watch: mean policy entropy, distinct-n-gram rate, KL to SFT reference (metrics).
  • Fix: entropy bonus; tighten KL; better reward (verifiable tasks); mix SFT data; early stop before entropy bottom.
Not the same as …
  • logit_collapse — softmax too peaked on one step; can happen in CE training without whole-trajectory repetition.
  • representation_collapse — encoder vectors identical; contrastive/SimCLR setup.
  • Neural collapse — supervised late-training class geometry, not “model says the same sentence every time.”
  • GAN mode collapse — generator fools D with few modes; WGAN / different losses (loss functions).
Gradients
Gradient explosion (explode)

Backprop multiplies Jacobians along the path from loss to weights. When that product grows without bound, one update can push weights into a region where activations or logits overflow. You see a sudden loss jump, Inf/NaN, or grad norms orders of magnitude above normal.

  • Watch in W&B: train/grad_norm, train/update_to_weight_ratio.
  • Fix: gradient clipping by global norm; lower learning rate; linear LR warmup (especially Post-LN transformers); residual + norm stacks (He et al.).
Gradient vanishing (vanish)

The opposite problem: repeated factors < 1 in the backward chain shrink the signal until deep layers (or long unrolled time steps) get near-zero updates. Training looks stuck even though the loss is not NaN.

  • Watch: flat loss; grad norm falling sharply from output toward input layers.
  • Fix: skip connections, LayerNorm, gated RNNs (LSTM/GRU) for long sequences; avoid pathological depth without residuals.
Optimizer
Adam instability (adam_collapse)

Adam scales each parameter by roughly η × m̂ / (√v̂ + ε). When v̂ is stale, tiny, or out of sync with the current gradient, the effective step can explode even if the raw gradient looks fine. LLM runs often show a mid-training loss spike rather than a slow drift.

  • Watch: train/adam_second_moment/*, train/adam_max_r, spike scores like g²/v (SPAM-style).
  • Fix: do not set ε absurdly small; clip gradients; use warmup; consider AMSGrad, moment reset after spikes, or tuned AdamW (Reddi; Zhang; Bai et al.).
  • Pair with: optimizers — this is not the same as picking the wrong loss scale on a stable run.
Attention & internal geometry
Attention sink (attention_sink)

Some heads put almost all mass on one key position (often the first token or a register). Other tokens get ignored, which hurts long-context and streaming decode. It is an attention-pattern pathology, not necessarily a grad explosion.

  • Watch: attention_max_weight, head imbalance metrics.
  • Fix: ViT-style register tokens; sink-aware KV in streaming models; initialization and architecture tweaks (Darcet; Xiao et al.).
Rank collapse (rank_collapse)

A weight matrix still has full rank on paper, but singular values show one dominant direction — the layer behaves like a low-rank map. Capacity drops; features can become redundant.

  • Not the same as: neural collapse (late-class geometry) or SSL dimensional collapse — see below.
  • Watch: train/effective_rank/* on weights.
  • Fix: often too much weight decay; reduce decay and compare singular value spectrum.
Logit collapse (logit_collapse)

The model outputs a very sharp softmax — one class or token dominates with probability ≈ 1. That hurts calibration and can mean the network stopped exploring useful logit directions early.

  • Watch: train/logit_entropy, expected calibration error (ECE).
  • Fix: label smoothing, temperature scaling at eval, LR warmup (Szegedy et al. motivation for smoothing).
Representation collapse (representation_collapse)

Hidden vectors for different inputs become nearly parallel — the encoder maps everything to the same direction. Common in contrastive learning without enough negatives (SimCLR-style trivial solution f(x) = const).

  • Watch: train/embedding_anisotropy, cosine similarities clustered near 1.
  • Fix: strong augmentations + many negatives; unfreeze more of the body; check batch size for contrastive.
Layer grad imbalance (layer_grad_imbalance)

One part of the network (embedding, head, last blocks) takes huge updates while the rest moves slowly — often from using one global LR when parts should move at different speeds (ULMFiT-style fine-tune).

  • Watch: train/update_ratio/* by parameter group.
  • Fix: discriminative learning rates — lower LR on pretrained body, higher on head.
MLM tutorial modes (encoder best practice)

These qlab runs show what happens when you skip standard BERT-style training hygiene — useful for comparing against a sane baseline in W&B.

  • no_warmup — Post-LN transformer at full LR from step zero; gradients near the top of the stack are huge at init (Xiong et al.). Fix: linear warmup or Pre-LN.
  • decay_norm_bias — weight decay applied to LayerNorm scale/bias, which many recipes exclude. Fix: decay only linear/embedding weights (AdamW param groups).
  • bad_mlm_mask — wrong mask ratio or masking policy for MLM. Fix: ~15% mask, consistent with pretrain literature; match tokenizer mask token.
Similar names, different problems
  • Neural collapse — late in supervised training, class features collapse to a simplex ETF; often discussed as geometry, not an emergency NaN (Papyan et al.).
  • Dimensional collapse — SSL covariance loses rank (Jing et al.); related spirit to representation collapse, different setup.
  • Dead ReLU — units stuck at zero; swap activation or LR (activations).
  • Catastrophic forgetting — sequential tasks erase old skills; multi-run lifecycle issue, not one bad step.
Chooser
  • NaN or spike → explode / adam_collapse checklist (clip, LR, ε, warmup).
  • Flat loss, healthy grads near output only → vanish or layer imbalance.
  • Train OK numerically, val bad → generalization, not this sheet.
  • RL reward up but all outputs identical → mode collapse (entropy, KL, reward design).
  • Pathology lab → pick a mode id, run tutorial baseline vs mode, diff signatures in W&B.
