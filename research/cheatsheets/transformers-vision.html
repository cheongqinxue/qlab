Image understanding encoders — patches, hierarchy, pretraining.

Transformers — vision

ViT (Vision Transformer)
  • Split image into patches → linear embed; add pos (often 1D order of patches)
  • Transformer encoder; [CLS] token or global average pool → head
  • Needs data + augment at scale; conv stem hybrids common
Hierarchical (multi-scale)
  • Swin — windowed self-attn + shifted windows; patch merge between stages
  • PVT / Twins — spatial reduction attention
  • DeiT — distillation token; training recipe for smaller ViTs
  • Fits detection / segmentation backbones better than flat ViT
CLIP / SigLIP
  • Image transformer + text transformer; contrastive image–text pairs
  • Zero-shot classify via text prompts; backbone for multimodal LLMs
  • SigLIP: sigmoid loss variant; common in newer stacks
Self-supervised encoders
  • DINO / DINOv2 — self-distillation; strong frozen features
  • MAE — mask high % of patches; reconstruct pixels or latents
  • BEiT / iBOT — discrete visual tokens as targets
Video understanding (short)
  • Spacetime patches or frame encoder + temporal transformer
  • Cost ∝ frames — tubelet embedding, sparse sampling
  • Generation patterns: image gen sheet
Pick encoder
  • General embed / search: DINOv2 or CLIP
  • Need pyramid features: Swin
  • Simple classify fine-tune: ViT + head
  • Core attn: core sheet
