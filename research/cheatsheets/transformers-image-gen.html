Latent diffusion with transformer backbones and token-based gen.

Transformers — image generation

Latent diffusion pipeline
  • VAE encodes image → latent grid; denoise in latent space; VAE decode
  • Text/image conditioning via cross-attn or dual-stream blocks
  • Scheduler steps (DDIM, Euler, etc.) wrap same denoiser
DiT (Diffusion Transformer)
  • ViT-like stack on latent patches; predicts noise ε or $v$-target
  • adaLN — timestep + class/label modulate norm scale/shift
  • Scales with compute; U-Net replacement in modern systems
MMDiT (e.g. SD3 / Flux-class)
  • Separate image and text token streams + shared transformer blocks
  • Joint attention between modalities inside block
  • Strong text rendering vs older U-Net diffusion
Token / AR generation
  • VQ-VAE — discrete visual codes; autoregressive transformer (Parti, Muse)
  • Mask modeling — parallel decode variants
  • Trade-off: long sequences vs diffusion quality at fixed compute
U-ViT & hybrids
  • U-Net skips + ViT bottleneck — bridge from conv era
  • Still seen in legacy checkpoints; new work favors pure DiT
Control & efficiency
  • ControlNet / T2I adapters — extra conditioning path; see PEFT sheet
  • Distillation / consistency models — fewer steps at inference
  • Video: spacetime latents + causal or bidirectional temporal blocks
