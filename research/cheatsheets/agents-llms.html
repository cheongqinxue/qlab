Agents — LLM comparison

Closed vs open weights

Closed (API) models run on the vendor’s GPUs — you pay per token, do not ship weights, and disk/VRAM are not your problem. Open-weight models let you download checkpoints, self-host, fine-tune, and audit — you own disk, VRAM, and ops (or pay a third-party inference host). For agents, the same pattern (tools + loop) applies; what changes is cost model, latency, data residency, and how you regression-test quality. Anthropic’s 5.x line includes Opus 5.5 (frontier general) and Fable 5.1 (top coding/reasoning tier; Mythos 5.1 is a limited-availability sibling at the same price). Google’s current agent stack is the Gemini 3 series (3.1 Pro, 3.8 Flash, plus 3 Flash / Flash-Lite tiers); 2.5 remains on the API but is largely superseded for new agent work. OpenAI’s API flagship line is GPT-6: Astra (max reasoning/coding), 6.1 Sol (near-Astra, default for hard agent work), 6.1 Terra (fast multimodal + computer use), and 6 Luna (volume/cost). Tool-heavy agents should use the Responses API on Sol/Astra per OpenAI docs.

Snapshot for API pricing, speed, and open-weight sizing: late Oct 2026 — verify Hugging Face cards before you standardize on a checkpoint. Benchmarks are vendor or leaderboard snapshots — SWE-bench Verified scores especially depend on agent scaffold, tools, and pass@1 vs multi-try. Verify before contracts: OpenAI, Anthropic, Google Gemini, and provider docs; speed medians from Artificial Analysis (standardized API workload).

Matrix legend
  • Modality — inputs→output; T text, I image, V video, A audio (T+I→T = text and image in, text out).
  • Context — max input tokens the model/API accepts in one request (not how much you should fill — agent loops burn context fast).
  • Disk — approximate download size for open weights (BF16/full and Q4_K_M GGUF where noted). API models: hosted.
  • VRAM — rough GPU memory to serve (weights + KV cache); open VRAM column is Q4 at ~4k tokens; scale up roughly linearly with context length self-hosted.
  • $/M — USD per million tokens on first-party API (input / prompt cache read / output). Gemini cache excludes hourly storage.
  • TTFT — time to first token (seconds). Speed — output tokens per second after first token.
  • SWE-bench V — SWE-bench Verified (real GitHub fixes). HumanEval — Python function completion (saturated at frontier).
  • Understanding — MMLU-Pro and/or GPQA Diamond (%). Tool use — BFCL v3/v4 or MCP-Atlas (%), when published.
  • Human eval — LMSYS Chatbot Arena Elo (text or code arena) where available; higher is better.

How to use benchmarks for agents
  • Coding agent — prioritize SWE-bench Verified and LiveCodeBench over HumanEval alone (HumanEval is saturated).
  • Tool-heavy agent — BFCL or MCP-Atlas plus your own golden tasks (schemas, idempotency, auth).
  • Research / analysis — GPQA, MMLU-Pro, MMMU for multimodal; add domain golden sets.
  • Chat product — Arena Elo tracks human preference but is not a safety or correctness guarantee.
  • Cost + latency — multiply tool-loop tokens; cache hits (Claude/OpenAI/Gemini) matter most on fixed system prompts and RAG prefixes.
  • Long context agents — prefer 128k+ API models or summarization / memory instead of stuffing full tool traces; self-host VRAM scales with context.
Agent-oriented chooser

Long repo or doc context — GPT-6.1 Sol / Gemini 3.1 Pro / Claude 1M (1.05M on GPT-6); compress old tool steps and keep RAG in cacheable prefixes. Low latency, many tool steps — GPT-6.1 Terra (non-reasoning), Gemini 3.8 Flash, GPT-4o, or GPT-6 Luna; cache system + tool definitions. Hard coding / repo edits — Claude Fable 5.1, GPT-6 Astra / 6.1 Sol, Opus 5.5, or Gemini 3.1 Pro; use Sol before Astra if cost matters; budget high TTFT on reasoning.effort=max. Computer-use / GUI agents — GPT-6.1 Terra or Gemini with computer-use tools; OpenAI expects Responses API + tool fees. Multimodal agents (PDF, audio, video in one thread) — Gemini 3.1 Pro or 3.8 Flash native multimodal I/O. On-prem frontier — Qwen3.8-27B or Gemma 4 31B Q4 on a 24–48 GB GPU; MoE at scale: Qwen3.8-Flash-Next, GPT-OSS-120B, DeepSeek V4.1-Flash. On-prem laptop / edge agent — Muse Glimmer-30B (24 GB), Nemotron 3.5 Lightning (80 GB BF16 or NVFP4 on Spark), LFM3-1.7B / LFM2.5-8B-A1B, Bonsai 2 9B, ZAYA1-8B, Granite 4.2-8B, MiniCPM5-8B. Multimodal local agent — Nemotron 3 Nano Omni (doc/video/audio agents on 32–80 GB), Muse Glimmer, Nemotron Super-VL or Bolt, LFM3-VL-2B, MiniCPM-V 4.6 (screenshots/PDFs on ~8–12 GB); budget VRAM for encoders and long multimodal context. Always run your golden agent eval — public benchmarks do not include your tools, data, or policies.
